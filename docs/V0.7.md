# DolosBlackMagic v0.7.0

## Added

- `site/platform/` semantic application layer.
- dependency-free application event bus.
- first-class investigation model for sources, bookmarks, findings, entities, notes, timeline and analyst actions.
- chunked `File`/`Blob` reader using bounded `Blob.slice()` operations.
- worker protocol v2 with `START`, `CHUNK`, `PROGRESS`, `PARTIAL_RESULT`, `COMPLETE`, `CANCEL` and `ERROR` messages.
- UTF-8 streaming decode with cross-chunk record boundary carry.
- deterministic streamed evidence IDs and provenance metadata.
- Event Explorer evidence drawer with normalized/raw comparison, bookmarks and entity pivots.
- query-history chips for Event Explorer.
- Detection Engine v3 nested conditions, grouped thresholds, distinct counting and bounded sequences.
- defensive correlation rules for authentication spray, success-after-failure and service-install/process sequences.
- v0.7 investigation snapshot validation.
- platform and streaming regression suites.

## Improved

- large file analysis no longer requires the entire `File` to be read through `File.text()` in the v0.7 streaming path.
- cancellation discards unfinished streaming analysis instead of committing partial analyst state.
- streamed telemetry keeps compact evidence provenance rather than requiring raw source persistence.
- Event Explorer rows are keyboard-inspectable and can pivot directly into evidence context.
- release integrity now validates v0.7 platform assets and release documentation.

## Security

- custom detection logic remains declarative data; no `eval()` or `new Function()` execution was introduced.
- v3 regex validation rejects malformed and common pathological patterns before execution.
- snapshot restore is schema validated and remains constrained to DolosBlackMagic investigation data.
- byte ranges are not fabricated when the streaming pipeline cannot determine them accurately.

## Testing

`npm test` now includes:

- existing core, log, SOC, operations and security regression suites;
- `tests/platform.test.mjs` for investigation persistence, snapshot validation and detection-v3 behavior;
- `tests/streaming.test.mjs` for worker protocol, bounded file slicing, UTF-8 decoder use, carry handling and provenance requirements;
- static integrity validation for all v0.7 platform/PWA assets.

## Deployment

The service-worker cache identity is `dbm-0.7.0`. Platform assets use relative paths compatible with GitHub Pages under `/DolosBlackMagic/`, Netlify root deployment and local HTTP hosting.

## Known limitations

- streaming is optimized for line-oriented telemetry. Large single-object JSON documents continue to be better handled by the existing non-streaming parser path until a streaming JSON adapter is introduced.
- the streaming worker retains normalized events up to a configured bound; it is not a disk-backed SIEM datastore.
- browser-local investigations remain single-user and endpoint-local by design.
- evidence byte offsets are intentionally left unset unless they can be measured accurately.
