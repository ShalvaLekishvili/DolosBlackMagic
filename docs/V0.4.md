# DolosBlackMagic v0.4 — SOC Operations Hardening

This release adds a new browser-side SOC Operations layer on top of BlackLog and Detection Studio.

## Ten completed improvements

1. Finding deduplication within a configurable time window.
2. Local suppression rules for alert-noise tuning (contains / equals / regex).
3. Lightweight event risk enrichment with public/private source, admin-service, privileged-user and high-interest-process tags.
4. Cross-event investigation mapping across hosts, users, IPs, processes and findings.
5. SOC operations dashboard metrics for events, actionable findings, open incidents and suppressed noise.
6. Pipeline health indicators for invalid timestamps, empty messages and duplicate ratio.
7. Portable workspace export for DolosBlackMagic `dbm.*` LocalStorage state.
8. Safe workspace restore limited to DolosBlackMagic-owned keys.
9. Responsive SOC Operations UI for desktop, tablet and mobile use.
10. Regression/deployment hardening: `ops.test.mjs`, static asset integrity checks, Node 24 CI wiring and PWA cache `dbm-v5`.

## Privacy and scope

All v0.4 operations features are local-first. Suppressions, rules, incidents, triage state and workspace backups remain in the browser unless the analyst explicitly exports a JSON snapshot. The risk-enrichment layer is contextual heuristics, not authoritative threat intelligence.
