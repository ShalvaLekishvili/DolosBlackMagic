# DolosBlackMagic v0.5.0

## Added

- Parse-quality accounting with malformed/partial record preservation.
- Rich normalized event fields for identity, process lineage, network, HTTP and hashes.
- Finding confidence, evidence, firing explanations, remediation and false-positive guidance.
- Expanded Windows/Sysmon/Linux/web defensive detection content and scheduled-task/cron coverage.
- Custom rule lifecycle, NOT/numeric operators and rule testing against loaded telemetry.
- Detailed Sigma-like/Wazuh import translation reports.
- Triage status history, disposition and severity override metadata.
- Versioned workspace validation/restore and dedicated regex execution safety guard.
- Finding evidence inspector, entity pivots, keyboard/focus/reduced-motion improvements.
- Professional architecture, log-format, detection, security, privacy and testing documentation.

## Improved

- Brute-force and port-scan correlation now use sliding windows.
- Event filtering is debounced and reuses cached search text.
- Event rendering is bounded to keep large investigation views responsive.
- Investigation graphs deduplicate edges and include domains, URLs and hashes with complexity bounds.
- PWA manifest and service-worker cache remain safe for GitHub Pages subpaths.

## Fixed

- Malformed NDJSON no longer aborts an entire ingestion.
- Invalid timestamps are no longer silently replaced with the current time.
- Workspace restore UI now handles structured validation results instead of displaying `[object Object]`.
- README/file-tree/version drift from earlier v0.3/v0.4 releases is removed.

## Security

- Workspace restore only accepts DolosBlackMagic-owned namespaces.
- Unsafe/invalid analyst regex patterns are rejected or excluded from execution.
- Netlify receives a self-contained CSP and stricter browser permission headers.
- Imported telemetry/rules continue to be treated as data and escaped before UI rendering.

## Testing

Parser tests expanded to malformed NDJSON, CSV escaping, RFC5424, Unicode/Georgian text, invalid timestamps, normalization and correlation boundaries. SOC, operations and security regression coverage was expanded. Static integrity now checks v0.5 assets, duplicate IDs, PWA cache membership, manifest subpath safety, package version and CSP presence.

## Deployment

GitHub Pages and Netlify continue to publish the static `site/` directory. PWA cache identifier is `dbm-v7` for this release.

## Known limitation

Large log parsing remains synchronous and memory-resident in v0.5. Filtering, rendering, correlation and graph work were optimized, but very large files can still spend noticeable time in main-thread parsing. This limitation is documented rather than represented as solved.
