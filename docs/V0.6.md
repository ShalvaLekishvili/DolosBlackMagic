# DolosBlackMagic 0.6.0

DolosBlackMagic 0.6.0 stabilizes the workstation generation that followed the v0.5 engine/security cycle. This release is intentionally focused on release integrity, analyst-facing workstation presentation, background log processing and deployment consistency rather than claiming a new backend architecture.

## Added

- Premium SOC/DFIR workstation visual layer in `v06-ui.css`.
- Analyst-oriented overview enhancements in `dashboard-v06.js`.
- Background large-log analysis through `log-worker.js` for payloads above the UI threshold.
- Explicit cancellation behavior that does not commit unfinished worker results.
- Bilingual English/Georgian project README and repository-hosted hero artwork.

## Improved

- Event Explorer responsiveness through background processing, bounded rendering and debounced filtering.
- PWA asset coverage now includes the log worker.
- Static integrity validation now derives the expected release from `package.json` instead of hardcoding an obsolete version.
- GitHub Pages and Netlify remain compatible with relative/subpath-safe static assets.

## Fixed

- Release drift where v0.6 UI assets coexisted with v0.5 package metadata.
- PWA cache naming that was independent from the product release.
- Static integrity coverage that omitted `log-worker.js`.

## Security & privacy

- Local-first processing remains the default.
- No telemetry, account, mandatory backend or automatic threat-intelligence upload was introduced.
- Uploaded artifacts and imported rules remain data and are not executed.

## Testing

The existing regression entry point remains:

```bash
npm test
```

Node.js 24+ is the supported runtime. Static integrity now validates required assets, navigation references, PWA cache coverage, subpath-safe manifest settings, README release alignment and Netlify CSP presence.

## Deployment

The static application continues to target GitHub Pages, Netlify and local HTTP hosting. The service-worker cache identifier for this release is `dbm-0.6.0`.

## Scope note

0.6.0 is the stabilized workstation release. The next engineering line targets the v0.7 Analyst Data Platform: streaming/chunked ingestion, stronger evidence provenance, Event Explorer v2, richer correlation primitives, first-class investigations and privacy-preserving persistence.
