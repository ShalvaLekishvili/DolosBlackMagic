# DolosBlackMagic v0.10.0

## Added

- optional local Python Wazuh analysis engine under `python-engine/`;
- resilient parser for direct JSON, arrays, NDJSON/JSONL, Wazuh API wrappers and Indexer/OpenSearch exports;
- Wazuh-aware normalization for Windows EventChannel, agent lifecycle, Linux auth, FIM, network, web and generic manager alerts;
- local HTTP API on `127.0.0.1:8765` plus CLI mode;
- Event Explorer Python Engine panel with health status, deep analysis, finding inspection and JSON export;
- Python regression suite and CI coverage.

## Improved

- preserves Wazuh rule ID separately from Windows Event ID;
- preserves agent IP separately from observed authentication/network source IP;
- preserves target and subject/requesting Windows identities separately;
- source Wazuh MITRE metadata remains source context rather than an automatic verdict;
- malformed NDJSON records are preserved as partial evidence instead of silently dropped.

## Detection content

The Python engine contains defensive analyst-assistance rules for Windows Security, Sysmon-style telemetry, Linux authentication/privilege activity, Wazuh agent lifecycle, FIM, network and web telemetry. Correlations include password guessing, password spray, RDP/network logon bursts, failure-to-success sequences, multi-port scanning and repeated agent connectivity changes.

## Security

- Python service binds to loopback by default;
- no cloud API or telemetry upload was introduced;
- request body is capped at 64 MB;
- browser CORS is limited to the DolosBlackMagic GitHub Pages origin and localhost development origins;
- imported telemetry is treated as data and never executed.

## Testing

CI now validates Node.js 24 browser tests and Python 3.12 Wazuh-engine tests.

## Deployment

GitHub Pages and Netlify remain static. Python is an optional analyst-side companion and is not required for the hosted application to load or operate in browser-only mode.
