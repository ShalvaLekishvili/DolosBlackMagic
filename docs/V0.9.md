# DolosBlackMagic v0.9.0

## Added

- canonical Detection Engine v3 integration into fresh, streamed and reopened telemetry analysis;
- `platform/detection-pipeline.js` for merged finding normalization, deduplication and evidence back-linking;
- analyst-facing finding classification (`informational`, `suspicious`, `correlated`, `high-confidence`);
- repeated-stage sequence semantics;
- defensive correlations for firewall multi-port activity, administrative-service sweeps and repeated web authentication denial patterns;
- dedicated detection-pipeline regression tests.

## Improved

- success-after-failure correlation now requires a real failure burst before success;
- grouped correlations skip events with missing required group keys instead of combining them into a shared placeholder group;
- telemetry rendering now reports the merged canonical finding set;
- normalized events receive detection rule back-links;
- README, architecture, detection and testing documentation now match v0.9 behavior.

## Fixed

- removed the architectural gap where Detection Engine v3 existed but was not automatically used by the canonical telemetry render path;
- corrected weak sequence semantics that could overstate evidence from a single failure followed by success;
- prevented unrelated events with absent grouping fields from forming false correlation buckets.

## Security

- detection rules remain declarative data;
- no JavaScript evaluation path was introduced;
- existing regex safety guards remain in effect;
- no external enrichment, telemetry upload or mandatory API was added.

## Testing

`npm test` includes dedicated v0.9 coverage for detection merge/deduplication, classification, event linkage, repeated-stage sequences and missing-group safeguards in addition to all prior suites.

## Deployment

The PWA cache identity is `dbm-0.9.0`, and the detection pipeline asset is required by both static integrity and service-worker cache validation.

## Limitations

- findings remain analyst-assistance signals, not authoritative malicious verdicts;
- Detection Studio custom-rule storage and Detection Engine v3 correlation content remain separate APIs during incremental consolidation;
- full browser end-to-end automation remains lighter than the Node regression suite.
