# DolosBlackMagic v0.8.0

## Added

- IndexedDB-backed Local Dataset Vault for opt-in telemetry persistence.
- dataset schema/version metadata and validation.
- event-count and approximate serialized-size safety bounds.
- browser storage usage/quota visibility where supported.
- optional durable-storage request.
- saved dataset reopen flow into Event Explorer.
- portable local JSON dataset export/import with schema validation and re-sanitization.
- active-investigation rebinding for imported datasets.
- storage regression suite.

## Improved

- telemetry renderer is reusable for fresh and persisted datasets.
- investigation data sources distinguish ephemeral and IndexedDB-backed retention.
- persisted dataset sources use deterministic identity/deduplication.
- Dataset Vault remains stable across investigation UI re-renders.
- README and architecture documentation describe the actual persistence boundary.

## Fixed

- removed the architectural gap where selected telemetry could only remain memory-resident or be exported manually.
- cyclic/unserializable raw event objects no longer break dataset preparation.
- PWA/static integrity requires the storage platform assets.
- static integrity now syntax-parses every production JavaScript asset before deployment.

## Security

- dataset persistence is explicit rather than automatic.
- arbitrary raw event objects are not stored; raw content is reduced to bounded previews.
- long untrusted fields are capped before persistence.
- imported datasets are validated, rebuilt and sanitized rather than blindly inserted into IndexedDB.
- dataset import files have an additional UI size guard.
- no network upload, remote API or executable rule path was introduced.

## Testing

`npm test` includes `tests/storage.test.mjs` for sanitization, schema validation, size/event bounds, cyclic raw data, portable import rebinding and untrusted-field truncation in addition to all prior suites. Static integrity also parses all production JavaScript with Node's parser to catch syntax regressions before Pages deployment.

## Deployment

The PWA cache identity is `dbm-0.8.0`. All Dataset Vault assets are same-origin, relative-path resources compatible with GitHub Pages, Netlify and local HTTP hosting.

## Limitations

- IndexedDB availability and quota are controlled by the browser.
- durable storage requests may be denied by the browser.
- each saved collection is limited to 50,000 events and approximately 24 MB by design.
- portable dataset JSON may contain sensitive normalized telemetry and must be handled accordingly.
- the vault is not a multi-user SIEM datastore and remains endpoint/browser-profile local.
