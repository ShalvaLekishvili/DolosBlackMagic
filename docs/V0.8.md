# DolosBlackMagic v0.8.0

## Added

- IndexedDB-backed Local Dataset Vault for opt-in telemetry persistence.
- dataset schema/version metadata and validation.
- event-count and approximate serialized-size safety bounds.
- browser storage usage/quota visibility where supported.
- optional durable-storage request.
- saved dataset reopen flow into Event Explorer.
- storage regression suite.

## Improved

- telemetry renderer is now reusable for fresh and persisted datasets.
- investigation data sources distinguish ephemeral and IndexedDB-backed retention.
- README and architecture documentation now describe the actual persistence boundary.

## Fixed

- removed the architectural gap where large telemetry could only remain memory-resident or be exported manually.
- PWA/static integrity now requires the storage platform assets.

## Security

- dataset persistence is explicit rather than automatic.
- arbitrary raw event objects are not stored; raw content is reduced to bounded previews.
- long untrusted fields are capped before persistence.
- no network upload, remote API or executable rule path was introduced.

## Testing

`npm test` includes `tests/storage.test.mjs` for sanitization, schema validation, size/event bounds and untrusted-field truncation in addition to all prior suites.

## Deployment

The PWA cache identity is `dbm-0.8.0`. All Dataset Vault assets are same-origin, relative-path resources compatible with GitHub Pages, Netlify and local HTTP hosting.

## Limitations

- IndexedDB availability and quota are controlled by the browser.
- durable storage requests may be denied by the browser.
- each saved collection is limited to 50,000 events and approximately 24 MB by design.
- the vault is not a multi-user SIEM datastore and remains endpoint/browser-profile local.
